# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 dataset/genesis_brand_dataset.md로 25초 데이터 모션그래픽을 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 차량 실루엣·막대·게이지·데이터 오브젝트가 변형·이동하며 "배지를 뗀 10년"을 한 문장으로 전달하는 영상이어야 합니다.

# 입력
- 주제: Genesis 2015–2026. 독립 브랜드 선언, 세단 3종 출발, SUV 전환, 연 20만 대, 누적 150만 대, 전동화, Magma와 르망, GV90까지
- 목적/타깃: 데이터 모션그래픽 쇼케이스 / 자동차·브랜드·데이터에 관심 있는 한국어권 시청자
- 핵심 메시지: 2015년 배지를 떼고 세단 세 대로 시작한 제네시스는 SUV로 판을 바꿔 연 20만 대를 넘겼고, 10년 만에 150만 대를 판 뒤 르망과 GV90으로 향한다.
- 데이터: 첨부 파일(유일한 소스)
- 마무리: "GENESIS 2015—2026" 텍스트 타이틀 + 데이터 기준일
- 브랜드 색/폰트: 아래 디자인 시스템에서 직접 설계(공식 브랜드 자산은 쓰지 않음)
- 언어: 헤드라인은 한국어, 마이크로 라벨은 영문 대문자

# 데이터 규칙
- 모든 수치·날짜·사실은 첨부 파일에서만 가져옵니다. 파일에 없는 값은 만들지 않으며, 표에 없는 연도·월은 비워 둡니다.
- 아래 씬 초안의 수치는 작성 시점의 스냅샷입니다. 첨부 파일 값과 다르면 파일 값으로 교체하고 카피도 그에 맞게 고칩니다.
- 출처 우선순위: 현대차그룹 발표 > 통신·언론(연합뉴스, 전자신문 등) > Wikipedia > 미국 판매 트래커. 범위·근사값은 대표값 1개를 고르고, 근사값이면 앞에 "~"를 붙입니다.
- 글로벌 연간 판매(§5.1 표)와 누적 보도(§5.1 마일스톤)는 섞지 않습니다. 연간 표를 합산해 누적이라고 쓰지 않습니다(파일 주석: 1,524,176 ≠ 1,510,368).
- 미국 브랜드 연간은 §5.4 파일 지침대로 B(CarBuzz) 열을 기본으로 씁니다. A(CarFigures)는 교차검증용이며 화면에 쓰지 않습니다.
- 2024 모델별 판매(§3.1)에서 GV80과 GV80 Coupe는 합산 셀(68,026)이므로 분리하지 않습니다. 비율은 파일의 share 열(분모 229,532)을 그대로 씁니다.
- 한국 연간은 완전한 시계열이 없으므로 시계열 차트로 그리지 않습니다. 확정 포인트(§5.2)만 씁니다.
- 출고·소매·수출 정의가 섞여 있으므로 서로 다른 정의의 값을 더하지 않습니다.
- "목표", "보도", "추정", "rumor"로 표시된 값(예: GV90 국내 가격 루머, IMSA 일정)은 쓰지 않습니다. 일정은 확정 사실(공개일·완주 등)만 씁니다.
- 한 차트에는 한 기준 열만 씁니다.
- 장식용 HUD 숫자는 연도·경과 연수·씬 번호·박 카운터처럼 파일이나 타임라인에서 파생된 값만 씁니다. 가짜 텔레메트리(속도·RPM 등 파일에 없는 계기 수치)는 금지합니다.
- 공식 로고·윙 엠블럼·워드마크·크레스트 그릴 형상·Magma(ㅁㄱㅁ) 로고를 재현하지 않습니다. 차량은 단순화한 일반 실루엣으로 그립니다. 파일 §10의 디자인 토큰(Two-line lamp, G-Matrix)은 "평행한 두 줄 빛", "다이아몬드 하프톤" 같은 추상 모티프로만 씁니다.

# 사양
- 1920×1080, 30fps, 25초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박(2초), 총 12씬. 12번 씬은 6박(3초)으로 남는 시간을 흡수합니다.
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지합니다. 박→프레임 변환은 누적 오차가 없는 함수로 계산합니다.

# 1단계: 스토리보드 (코드 작성 전에 prompt/STORYBOARD.md로 출력)
1. 데이터 사용표: 화면 표기값 / 파일 원문 값 / 섹션 / 처리 방식(대표값·근사·원문 그대로)
2. 카피 체인 확정본: 씬 초안 기반, 씬당 헤드라인 1개, 최대 2줄
3. 씬 표: 번호 / 역할 / 배경 / 카피 / 시그니처 모션 / 박별 이벤트(b1~b4) / 다음 씬 전환
4. 초안에서 바꾼 부분과 그 이유

# 데이터→비주얼 매핑
- 브랜드 독립 선언(§0·§1, 2015-11-04) → 네임플레이트 "HYUNDAI GENESIS"에서 "HYUNDAI" 글자가 떨어져 나가는 텍스트 분리 + 날짜 스탬프
- 선행 계보(§1: 2003 Concept Genesis, 2008 Hyundai Genesis 세단, 2015 브랜드) → 연도 롤러

- 첫 SUV와 판매 변곡점(§1 GV80 2020-01, §5.1 2019 77,135 → 2020 132,450, +71.7%) → 세단 실루엣이 SUV 실루엣으로 모핑 + 막대 점프
- 글로벌 연간 판매(§5.1, 2015–2025) → 막대 성장 + 200,000 기준선 돌파
- 2024 모델별 판매(§3.1) → 레이스 바, SUV 합(~65.4%) → 진행 링
- 미국 브랜드 연간(§5.4 B열)과 경쟁 비교(2024 Infiniti 추월) → 라인 드로잉 + 추월 지점 크로스 마커, 2016 대비 배수 → 대형 숫자

- GV90(§8: 2026-08-19 공개, 5,285 mm, 123.5 kWh, 800V 350 kW 10–80% ≈22분) → 실루엣 등장 + 배터리 셀 채우기
- 같은 데이터가 다시 나올 때는 형식을 바꿉니다(예: 1,510,368 = 카운트업 → 몽타주 대형 숫자, SUV 65.4% = 레이스 바 합 → 링 → 몽타주 숫자).

# 모션 규칙
- 등장은 back/spring 오버슈트, 퇴장은 expo.in, 스태거 40~80ms
- 씬마다 시그니처 모션 1개. 씬 초안의 전환 기법은 서로 중복하지 않습니다.
- 가능한 전환은 매치 컷으로 처리합니다(이전 씬의 오브젝트가 다음 씬의 주인공이나 배경이 됨).
- 카운터는 목표값에서 정확히 멈춘 뒤 최소 1박 유지합니다.
- 어떤 요소도 1박 이상 완전히 정지하지 않습니다(미세 스케일, 패럴랙스, 글로우 호흡).

# 금지
- 불릿·표 화면, 한 화면에 3문장 이상, 데이터 전체 동시 노출
- 페이드만으로 된 전환, 음악과 무관한 타이밍
- 파일에 없는 수치, 가짜 텔레메트리, 공식 로고·엠블럼·워드마크 재현, 루머·목표치를 사실처럼 표기

# 기술 요구 (저장소 규칙: 1. SpaceX Motion 구조를 따름)
- index.html + css/ + js/로 분할합니다. 하나의 거대한 파일로 만들지 않습니다. 씬은 js/scenes/NN-<역할>.js로 씬당 파일 하나.
- 외부 의존성 금지(CDN, 웹폰트 CDN, npm 런타임). 일반 <script defer> + 전역 네임스페이스로 짜서 file://과 GitHub Pages에서 바로 재생되게 합니다.
- 1920×1080 무대를 고정하고 뷰포트에 맞춰 scale합니다.
- render(t)가 모든 상태를 t로부터 계산합니다(실시간 타이머 의존 금지, 랜덤은 시드 고정). window.seek(t)를 노출합니다.
- 1,000칸 그리드처럼 요소가 많으면 canvas, 나머지는 SVG/DOM으로 그립니다.
