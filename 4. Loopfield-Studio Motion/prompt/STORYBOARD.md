# Loopfield Studio · 스토리보드 (1단계)

- 1920×1080 · 30fps · 25초 · 120 BPM (1박 = 0.5초 = 15프레임)
- 씬 01–11 = 4박(2초), 씬 12 = 6박(3초) → 총 50박 = 750프레임
- 박→프레임: `frame = beat × 15` (절대 박 번호에서 바로 계산)
- 전환은 경계 4~5프레임 전에 시작해 박에 착지. 카운터는 목표값 도달 후 1박 이상 유지
- 검증 수치에는 조건(표본 수 · 해상도 · 날짜)을 항상 같이 붙임
- 무드: 화면 전체가 셰이더 캔버스. 씬 배경은 Loopfield 프리셋을 실제 GLSL(WebGL 2)로 렌더한 패턴이고, 전환 11개는 라이브러리 패턴의 수학으로 만든 전환 셰이더. 그 위에 작도선과 모노 라벨이 얹혀 기하 구성이 보이게 함

## 5. 설계 결정과 그 이유

1. **패턴을 그림으로 흉내 내지 않고 실제로 렌더**: 프리셋 GLSL을 WebGL 2로 옮겨 그립니다. Loopfield가 만드는 것이 바로 이 패턴이라, 같은 수식으로 그려야 "무엇인지" 알아볼 수 있습니다. 렌더러(tools/render.mjs)가 쓰는 headless Chrome에서 WebGL 2가 하드웨어 GPU로 동작하고, 1080p 망델브로 160회 반복이 프레임당 약 4ms인 것을 미리 확인했습니다(이 측정은 우리 렌더 환경 확인용이며 화면에 쓰지 않습니다).
2. **전환을 라이브러리의 수학으로**: 이전 세 작품의 전환(스트립 셔터, 링 버스트, 아이리스, 슬라이스 글리치, RGB 색수차, 모션블러 슬라이드, 클록 와이프, 카메라 워크 11종)과 하나도 겹치지 않게, 프리셋 9종의 수학과 앱 기능 2종으로 전환 11개를 만들었습니다. 전환 하나하나가 Loopfield가 무엇을 할 수 있는지 보여 주는 장면이 됩니다.
3. **작도선으로 기하 구성을 드러냄**: 패턴만 돌면 "예쁜 배경"으로 보일 수 있어, 패턴 전에 축 · 동심원 · 대칭축 · 격자 · 분할선을 먼저 그립니다. 작도선 옆 숫자는 데이터셋 값만 씁니다.
4. **색은 데이터셋 값으로만**: 배경 5색은 기본 배경색 #080b12, 모노 팔레트 #f7f4ed, 오로라 팔레트 3색이고, 텍스트 잉크는 테마색 #111318입니다. 패턴은 6개 팔레트 값으로 칠합니다. 밝은 배경 씬의 패턴은 잉크 선화로 바꾸거나 나이트 창 안에 넣어 글자 대비를 지킵니다. 텍스트와 UI에는 글로우를 쓰지 않고, 블룸은 앱 기본값(0.35) 이하로만 씁니다.
5. **검증 수치는 조건과 함께**: 루프 경계 32/32는 표본 4장 · 320×180 · 평균절대오차 ≤ 0.5/255 조건을 붙이고, 데이터셋 원문대로 "전 픽셀 · 전 시간 연속성 증명이 아님"을 작은 라벨로 남깁니다. 네이티브 인코딩 표본도 해상도 · fps · 길이 · 프레임 · 코덱 · 날짜를 함께 씁니다. SwiftShader 테스트 환경 결과는 성능 주장으로 쓰지 않습니다.
6. **반복 횟수 단계는 숫자 없이**: 01의 1 → 128 단계는 수식이 패턴으로 자라는 과정을 보여 주는 연출이고, 앱 슬라이더 범위(48–384) 밖이라 숫자로 표기하지 않습니다. 화면에 숫자로 쓰는 것은 기본값 160뿐입니다.
7. **레이어 1·2는 예제 01, 3·4는 시연**: L1·L2는 예제 「겹쳐지는 궤도」의 값을 그대로 쓰고, L3·L4는 블렌드 5종을 보여 주기 위한 조합이라 프리셋 이름과 블렌드 이름 외의 수치를 붙이지 않습니다.
8. **장미 곡선은 잉크 선화로**: rose 프리셋은 검은 배경 위 발광으로 그려지지만, 06은 페이퍼 배경이라 같은 극방정식을 잉크 선으로 그립니다(앱의 multiply 블렌드와 모노 팔레트 느낌).
9. **도메인은 사용자 지정 표기**: 데이터셋의 실행 주소는 jtech-co.github.io/Loopfield-Studio/이고, 엔드카드의 Loopfield.studio는 요청하신 표기입니다. 데이터 사용표에 출처를 구분해 두었습니다.
10. **로고 사용**: 이전 작품에서는 다른 회사 로고를 그리지 않았지만, Loopfield의 궤도 로고는 같은 제작자(JTech Co.)의 자산이라 엔드카드에 작도선으로 그립니다. 빼기를 원하시면 텍스트만 남기겠습니다.
11. **영상 사운드는 장식**: Loopfield는 무음 MP4를 출력합니다(F34 오디오 트랙 0). 이 영상의 120 BPM 트랙은 시리즈 형식이며, 앱에 오디오 기능이 있는 것처럼 보이는 표기(파형 UI, 오디오 라벨)는 넣지 않습니다.
12. **세 번 이상 재등장**: 32(시트 → 몽타주 → 서브카피), 4K(프레임 → 몽타주 → 서브카피), 계정 0(기기 다이어그램 → 몽타주 → 서브카피), 루프(줄리아 궤도 → 몽타주 32/32 → 마지막 HUD 위상 0.999)가 서로 다른 형식으로 다시 나옵니다.
13. **구현 배치**: 저장소 규칙의 폴더 구조를 그대로 두고, WebGL 2 렌더러와 프리셋 셰이더는 js/fx/에 둡니다. 렌더 파일 이름은 loopfield-studio, 미리보기 포트는 5181입니다.
