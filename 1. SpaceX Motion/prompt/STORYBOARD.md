## 4. 초안에서 바꾼 부분과 이유

1. **06 막대를 가로 막대로**: 05의 "탈리 마크가 눕혀져 막대가 되는" 매치 컷과 07로 가는 "막대가 휘어 링" 모프가 모두 가로 막대에서 자연스럽습니다. 성장은 b1~b3에 구간 단위로 하고, b4를 2025 강조에 씁니다. 그래야 170이 전환 전에 1박 이상 유지됩니다.
2. **06 카피 줄바꿈**: "1년에 170번."을 "1년에 / 170번."으로 나눴습니다. 오른쪽 차트 영역을 확보하기 위해서입니다. 문구는 그대로입니다.
3. **09 구독 시점 8개 → 7개**: 2020 "<10k"는 부등식이라 카운트업 목표값이 될 수 없고, 2026-06-04 "12.0M 돌파"는 06-30 12.0M과 겹칩니다. 7개를 8분음표 e0~e6에 두면 최종값 12.0M이 b4 시작에 도달해 1박을 유지합니다.
4. **08 시계열**: 파일 차트에 2022가 없어 건너뜁니다. 최종값은 차트의 11130 대신 같은 출처 표의 정밀값 11,133을 씁니다.
5. **07 링 타이밍**: 두 링을 b1~b2에 채우고 b3~b4는 유지합니다. 카운터가 목표값에서 1박 이상 멈춰 있어야 하기 때문입니다.
6. **11 컷 4·5 형식 변경**: 2,213 t는 07에서 카운터로 나왔으므로 몽타주에서는 고객/내부 누적 막대로 바꿨습니다. 37(탈리 → 대형 숫자), $85.7B(10의 칩 → 대형 숫자)도 형식을 바꿔 다시 등장합니다.
7. **12 6박 배분**: b1 발사, b2 핫 스테이징·궤도, b3 V3 전개, b4 서브카피, b5 타이틀·기준일과 마지막 히트, b6 정지(미세 모션)로 나눴습니다.
8. **단일 HTML → 분할 파일**: 요청에 따라 `index.html` + `css/` + `js/`로 나눴습니다. 모두 classic script라 `file://`로 열어도, GitHub Pages로 열어도 그대로 동작합니다.
9. **웹폰트**: 외부 의존성을 두지 않기 위해 CDN을 쓰지 않습니다. 설치된 Pretendard Black과 JetBrains Mono를 `local()`로 먼저 찾고, 없으면 Noto Sans KR / Apple SD Gothic Neo / Malgun Gothic, Cascadia Mono / Consolas 순서로 폴백합니다.
10. **Puppeteer → 무의존 CDP 스크립트**: 렌더 스크립트는 Puppeteer와 같은 Chrome DevTools Protocol을 Node 내장 `WebSocket`으로 직접 호출합니다. `npm install` 없이 설치된 Chrome/Edge와 ffmpeg만으로 MP4를 만듭니다.
