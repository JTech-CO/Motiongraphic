# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 SpaceX_Dataset_2002-2026.md로 25초 데이터 모션그래픽을 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 로켓·궤도·데이터 오브젝트가 변형·이동하며 "24년의 궤적"을 한 문장으로 전달하는 영상이어야 합니다.

# 입력
- 주제: SpaceX 2002–2026. 창업, 첫 궤도, 재사용, Starlink, 상장, Starship 첫 궤도까지
- 목적/타깃: 데이터 모션그래픽 쇼케이스 / 테크·우주에 관심 있는 한국어권 시청자
- 핵심 메시지: 1억 달러와 세 번의 실패로 시작한 회사가 로켓을 재사용해 세계 발사의 절반을 맡고, 2026년 Starship으로 궤도에 닿았다.
- 데이터: 첨부 파일(유일한 소스)
- 마무리: "SPACEX 2002—2026" 텍스트 타이틀 + 데이터 기준일
- 언어: 헤드라인은 한국어, 마이크로 라벨은 영문 대문자

# 데이터 규칙
- 모든 수치·날짜·사실은 첨부 파일에서만 가져옵니다. 파일에 없는 값은 만들지 않으며, 표에 없는 연도는 비워 둡니다.
- 아래 씬 초안의 수치는 작성 시점의 스냅샷입니다. 첨부 파일 값과 다르면 파일 값으로 교체하고 카피도 그에 맞게 고칩니다.
- 범위·근사값(예: 134~138, ~99.5%)은 파일 §8 우선순위(회사 공시 > 독립 카탈로그 > 언론)로 대표값 1개를 고르고, 근사값이면 앞에 "~"를 붙입니다.
- 한 차트에는 한 기준 열만 씁니다. 연도별 발사는 §2.2 "SpaceX 총 궤도/시험" 열을 사용합니다.
- 장식용 HUD 숫자는 연도·경과 연수·씬 번호·박 카운터처럼 파일이나 타임라인에서 파생된 값만 씁니다. 가짜 텔레메트리 수치는 금지합니다.
- 공식 로고·워드마크·미션 패치를 재현하지 않습니다. 로켓은 단순화한 일반 실루엣으로 그립니다.

# 사양
- 1920×1080, 30fps, 25초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박(2초), 총 12씬. 12번 씬은 6박(3초)으로 남는 시간을 흡수합니다.
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지합니다. 박→프레임 변환은 누적 오차가 없는 함수로 계산합니다.

# 1단계: 스토리보드 (코드 작성 전에 출력)
1. 데이터 사용표: 화면 표기값 / 파일 원문 값 / 섹션 / 처리 방식(대표값·근사·원문 그대로)
2. 카피 체인 확정본: 씬 초안 기반, 씬당 헤드라인 1개, 최대 2줄
3. 씬 표: 번호 / 역할 / 배경 / 카피 / 시그니처 모션 / 박별 이벤트(b1~b4) / 다음 씬 전환
4. 초안에서 바꾼 부분과 그 이유

# 데이터→비주얼 매핑
- 설립 자본(§1) → 대형 숫자 카운트업
- Falcon 1 시도 5회·실패 3회(§1, §2.1) → 발사 슬롯 + 박마다 FAILED 도장
- 첫 궤도(§1, 2008-09-28) → 궤적 아크 드로잉
- 1단 착륙 성공/시도(§2.4) → 진행 링
- 최다 비행 부스터·최단 턴어라운드(§2.4) → 탈리 마크 누적, 카운트다운 시계
- 연도별 발사(§2.2) → 막대 성장
- 세계 발사 점유·궤도 질량 점유(§1, §2.2) → 이중 링 게이지
- Starlink 궤도 잔존 시계열(§4.1) → 지구 둘레 위성 점 증식 + 카운터
- 구독 시계열·국가 수(§4.2) → 카운트업 + 도트 매트릭스
- 주가 포인트(§6.2)·IPO(§6.1) → 라인 드로잉 + 포인트 팝업
- 차량 높이(§3.3) → 실루엣 스케일 비교
- Starship Flight 14 V3 전개 기수(§2.5) → 점 분리 전개
- 같은 데이터가 다시 나올 때는 형식을 바꿉니다(예: 37회 = 탈리 마크 → 몽타주 대형 숫자).

  · 헤드라인: Pretendard Black, 대형, 좁은 자간
  · 마이크로 라벨: JetBrains Mono, 대문자, 넓은 자간
  · 모든 숫자: tabular-nums(카운터 흔들림 방지)
  · 웹폰트 로드 실패 시 system-ui / monospace로 폴백
- 상시 HUD
  · 네 모서리 크롭마크
  · 좌상단 "0N / 12 — 역할"
  · 우상단 "SPACEX 2002→2026 · 120 BPM" + 4칸 박 인디케이터
  · 하단: 진행바 대신 2002~2026 연도 눈금자. 현재 씬이 다루는 연도·구간을 하이라이트하고 박에 맞춰 이동하며, 12번 씬에서 전 구간이 점등
  · 좌하단 "DATA AS OF 2026-09-29 · SRC: 씬별 출처(파일 §8 기준)"

- 질감: 그레인, 도면 격자(페이퍼 씬), 저밀도 별 필드 패럴랙스(다크 씬), 궤도 동심원 가이드, 방사형 글로우
- 오브젝트: 로켓·부스터·지구는 단색 플랫 벡터 + 가는 라인 디테일. 네온 글로우와 다색 그라데이션은 금지

# 모션 규칙
- 등장은 back/spring 오버슈트, 퇴장은 expo.in, 스태거 40~80ms
- 씬마다 시그니처 모션 1개. 씬 초안의 전환 기법은 서로 중복하지 않습니다.
- 가능한 전환은 매치 컷으로 처리합니다(이전 씬의 오브젝트가 다음 씬의 주인공이나 배경이 됨).
- 카운터는 목표값에서 정확히 멈춘 뒤 최소 1박 유지합니다.
- 어떤 요소도 1박 이상 완전히 정지하지 않습니다(미세 스케일, 패럴랙스, 글로우 호흡).

# 금지
- 불릿·표 화면, 한 화면에 3문장 이상, 데이터 전체 동시 노출
- 페이드만으로 된 전환, 음악과 무관한 타이밍
- 파일에 없는 수치, 가짜 텔레메트리, 공식 로고 재현

# 기술 요구
- 단일 HTML. 1920×1080 무대를 고정하고 뷰포트에 맞춰 scale합니다.
- render(t)가 모든 상태를 t로부터 계산합니다(실시간 타이머 의존 금지, 랜덤은 시드 고정). window.seek(t)를 노출합니다.
- 위성 점처럼 수천 개 이상인 요소는 canvas, 나머지는 SVG/DOM으로 그립니다.
- 파일에서 옮긴 값은 const DATA = {...} 한 곳에 모으고, 모든 씬은 DATA만 참조합니다.
- 오디오: WebAudio로 120 BPM 트랙을 생성합니다.
  · 기본: 킥 1·3박, 클랩 2·4박, 하이햇 8분음표, 서브 드론
  · 03·12번 씬 발사 구간: 노이즈 럼블 + 필터 스윕
  · 11번 씬: 하이햇 16분음표로 밀도 상승
  · 12번 씬 끝: 리버브 꼬리
  · 같은 트랙을 OfflineAudioContext로 WAV 렌더하는 함수도 제공합니다.
- 컨트롤: 재생/정지, 스크럽 바, 박 그리드 오버레이 토글, 씬 점프
- 별도 스크립트: Puppeteer로 t=i/30마다 seek → 캡처하고, WAV와 함께 ffmpeg로 MP4를 출력합니다.
