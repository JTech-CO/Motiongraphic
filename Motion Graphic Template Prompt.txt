# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 아래 입력으로 {{DURATION}}초 모션그래픽을 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 오브젝트가 변형·이동하며 한 문장의 이야기를 전달하는 영상이어야 합니다.

# 입력
- 주제/제품: {{SUBJECT}}
- 목적/타깃: {{GOAL}} / {{AUDIENCE}}
- 핵심 메시지(한 문장): {{KEY_MESSAGE}}
- 데이터(JSON): {{DATA_JSON}}
- CTA: {{CTA}}
- 브랜드 색/폰트: {{BRAND}} (비어 있으면 직접 설계)
- 언어: {{LANG}}

# 사양
- {{W}}×{{H}}, {{FPS}}fps, {{DURATION}}초, {{BPM}} BPM
- 1씬 = 4박. 씬 수 N = floor(DURATION ÷ (240/BPM)), 남는 시간은 마지막 씬이 흡수
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지

# 1단계: 스토리보드 (코드 작성 전에 출력)
1. 카피 체인: 핵심 메시지를 N조각으로 나눠 씬당 1조각. 쉼표나 미완결로 끝나 다음 씬으로 이어지게. 씬당 헤드라인 1개, 최대 2줄.
2. 데이터→비주얼 매핑 표: 아래 사전에서 선택. 주요 데이터는 서로 다른 형식으로 최소 3회 재등장.
3. 씬 표: 번호 / 역할 / 배경색 / 카피 / 시그니처 모션 1개 / 박별 이벤트 / 다음 씬으로의 전환.

# 데이터→비주얼 사전
- 항목 목록 → 알약 안 고속 사이클+카운터, 궤도 칩, 타일 모자이크
- 비율·잔량 → 진행 링, 게이지 바늘, 막대, 대형 숫자 카운트업
- 상태(on/off, 완료) → 도장, 체크박스+형광펜, 토글
- 시간·기한 → 시계 다이얼, 카운트다운
- 비교·순위 → 3D 카드 덱(부채꼴), 레이스 바
- 시계열 → 라인 드로잉, 스크럽 숫자
- 규모·수량 → 그리드 채우기, 아이콘 증식
- 절차 → 단계 진행 링, 설치 바

# 씬 역할 라이브러리
HOOK(최고 속도, 충격) / PROBLEM / REVEAL(3D 오브젝트 공개) / PROCESS / PROOF(데이터) / FEATURE(체크) / MONTAGE(8분음표 하드컷 가속) / END CARD(정지, 여백, CTA)
에너지 곡선: 빠름 → 중간 → 가속 → 정지

# 디자인 시스템
- 5색 로테이션: 다크 1, 브랜드 원색 2, 뉴트럴 페이퍼 1, 강조색 1. 씬마다 배경 교체
- 타이포: 헤드라인은 초굵은 산세리프 대형, 마이크로 라벨은 모노스페이스 대문자
- 상시 HUD: 크롭마크, "0N / 0N — 역할", "브랜드 · BPM"+4칸 박 인디케이터, 하단 N분할 진행바, 헤드라인 위 영문 캡션(타이핑+커서)
- 질감: 그레인, 미세 그리드 또는 하프톤, 방사형 글로우, 배경 다이얼 링
- UI 목업: 창 버튼, 경로, 바코드, 페이지 번호 등 실물 수준 디테일

# 모션 규칙
- 등장 back/spring 오버슈트, 퇴장 expo.in, 스태거 40~80ms
- 씬마다 시그니처 모션 1개, 전환 기법 중복 금지(링 버스트, 폭발→수렴 모핑, 아이리스 팽창, 스트립 셔터, 슬라이스 글리치, RGB 색수차, 모션블러 슬라이드, 하드컷 중 선택)
- 가능한 전환은 매치 컷: 이전 씬 오브젝트가 다음 씬의 배경이나 주인공으로 변형
- 어떤 요소도 1박 이상 완전 정지 금지(미세 스케일, 패럴랙스, 글로우 호흡)

# 금지
- 불릿, 표, 한 화면 3문장 이상, 데이터 전체 동시 노출
- 페이드만으로 된 전환, 음악과 무관한 타이밍

# 기술 요구
- 단일 HTML, 무대 {{W}}×{{H}} 고정 후 뷰포트에 맞춰 scale
- render(t)로 모든 상태를 t에서 계산(실시간 타이머 의존 금지, 랜덤은 시드 고정), window.seek(t) 노출
- 오디오: {{AUDIO}}가 있으면 동기 재생, 없으면 WebAudio로 BPM 킥/클릭 생성
- 컨트롤: 재생/정지, 스크럽 바, 박 그리드 오버레이 토글
- 별도 스크립트: Puppeteer로 t=i/FPS마다 seek→캡처, ffmpeg로 음원 합성해 MP4 출력

# 진행
1단계 스토리보드를 출력하고 제 확인을 받은 뒤 2단계 구현으로 넘어갑니다.
