# DJI 2006—2026 · 스토리보드 (1단계)

- 1920×1080 · 30fps · 25초 · 120 BPM (1박 = 0.5초 = 15프레임)
- 씬 01–11 = 4박(2초), 씬 12 = 6박(3초) → 총 50박 = 750프레임
- 박→프레임: `frame = beat × 15` (절대 박 번호에서 바로 계산)
- 전환은 경계 4~5프레임 전에 시작해 박에 착지. 카운터는 목표값 도달 후 1박 이상 유지
- 추정치에는 `EST.` 라벨과 `~`(헤드라인은 "약"), 점유율에는 지표 · 지역 · 기간 · 출처 라벨을 항상 붙임
- 무드: 카메라가 풍경 위를 날며 데이터를 찍는 한 번의 비행. 씬마다 시간대가 바뀌고(밤 → 새벽 → 낮 → 안개 → 황혼), 전환은 모두 카메라 워크

## 5. 초안에서 바꾼 부분과 이유

**검수 반영 (무드 · 전환 · 제품 조사)**

1. **무드를 "촬영하는 비행"으로**: 이전 작품처럼 무대 위에서 오브젝트가 변형되는 방식에서, 카메라가 풍경 위를 날며 데이터를 찍는 방식으로 바꿨습니다. 공용 풍경 층(능선, 등고선, 구름, 해)이 씬마다 시간대를 바꾸며 이어지고, 활공 패럴랙스·스피드 스트릭·뷰파인더 HUD·레터박스로 속도·활공·촬영·풍경을 드러냅니다.
2. **전환 11개를 모두 카메라 워크로 교체**: 초안의 폭발→수렴, 링 버스트, 스트립 셔터, 모션블러 슬라이드, 아이리스, 슬라이스 글리치, RGB 색수차는 SpaceX·Genesis에서 이미 쓴 기법이었습니다. 크레인 업, 틸트 업, 피치 다운, FPV 다이브, 랙 포커스, 셔터 캡처, 하이퍼랩스, 오빗, 구름 통과, 줌 스텝, 짐벌 수평 와이프로 바꿨습니다. BPM과 전환 타이밍(박 3~5프레임 전 시작, 박 착지)은 그대로입니다.
3. **이전 작품의 연출 장치 제거**: 연도 롤러는 웨이포인트로, 창업 도장은 위치 핀으로, 규제 도장 연타는 늘어나는 비행 제한 구역(지오펜스)으로, 링 게이지는 비행 경로·축척 막대·스크럽 바로 바꿨습니다.
4. **HUD를 뷰파인더로**: 크롭마크는 뷰파인더 코너 브래킷으로, 하단 연도 눈금자는 웨이포인트가 찍힌 비행 경로 위를 드론 마커가 활공하는 형태로 바꾸고, ● REC와 타임라인 타임코드를 더했습니다. 타임코드는 파일 수치가 아니라 타임라인에서 계산한 장식값입니다.
5. **팔레트를 풍경용으로**: 티타늄 그레이 대신 산 능선의 릿지 슬레이트를 넣고, 그래파이트·호라이즌 블루·클라우드 페이퍼를 밤·하늘·안개 톤으로 조정했습니다. 풍경은 같은 색의 명도 단계만으로 원근을 표현합니다.
6. **제품 디자인 조사 반영**: 7개 제품의 공식 치수와 제품 사진을 조사해 식별 포인트를 4절에 정리했습니다. 초안보다 구체적인 특징(팬텀 앞 암의 빨간 띠와 곧은 랜딩기어, Mavic 4 Pro의 렌즈 3개 둥근 헤드, Pocket 3의 가로 회전 화면과 빨간 링 버튼, Action 5 Pro의 빨간 렌즈 링)을 넣었습니다.
7. **씬 연출 변경**: 03은 격자 대신 원근감 있게 하늘을 채우는 편대로, 05는 게이지 대신 지형 위로 늘어나는 경로와 스크럽 바로, 09는 로그 사다리 막대 대신 로그 눈금을 고도층으로 쓴 상승 비행으로, 10은 지도 위 제한 구역으로 바꿨습니다. 06→07은 사진이 Pocket 3 화면에 담기는 매치 컷, 07→08은 빛 궤적이 차트 선이 되는 매치 컷입니다.

**데이터 처리 (초안에서 유지)**

8. **04 도트 배분**: 1,000개 도트를 83.48 : 9.82 : 1.40 : 5.30에 맞춰 835 : 98 : 14 : 53으로 나눴습니다. 최대 잉여 방식으로 합을 1,000에 맞췄고, 라벨은 원문 값을 씁니다.
9. **03 매출은 라벨로만**: 매출 차트는 09에서 한 번만 그리고, 03에서는 2013·2014 값을 라벨로만 보여 줍니다.
10. **07 가이던스는 범위 그대로**: 30–40만 범위를 밴드로 그리고, 파생 배수를 만들지 않습니다.
11. **08 IDC 73%는 별도 칩**: 액션캠 매출 점유와 핸드헬드 스마트캠 출하 점유는 정의가 달라 같은 차트에 올리지 않습니다.
12. **09는 로그 눈금 4개 점**: 품질이 낮은 2016~2024 추정은 빼고 출처가 분명한 4개 점만 씁니다.
13. **10 과장 방지**: FCC Covered List는 신규 모델 인증만 막았으므로 EXISTING MODELS STILL SOLD를 함께 표기하고, 헤드라인도 "신제품 문"으로 범위를 좁혔습니다.
14. **12 세 번째 등장**: 서브카피에 플래그십 스펙과 Pocket 3 누적을 다시 넣어, 두 데이터가 서로 다른 형식으로 세 번째 등장합니다(경로·막대 → 몽타주 숫자 → 서브카피).
15. **줌 스텝 라벨**: Mavic 4 Pro의 초점거리는 파일(T11)에 있는 28mm·168mm만 씁니다. 공식 스펙의 70mm는 파일에 없어 쓰지 않습니다.
